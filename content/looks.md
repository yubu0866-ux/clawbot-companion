# 妆容与发型（内容包示例）

> 仅在角色设定需要时使用；男性角色或不需要妆容描写的角色可只保留发型部分。可自行扩充。
> 妆容级别名须与程序的类别映射一致（通勤淡妆 / 日常淡妆 / 素颜 / 正式妆），
> 也可在内容包放 category_makeup.json 覆盖映射。

## 结构

`妆容分级（级别名 + 构成描写）`、`发型池（名称 + 适用场合）`，条目格式为「- 名：述」。

## 妆容分级
- 素颜：只做基础护肤描写，不强调彩妆；居家、运动场景常用。
- 日常淡妆：底妆轻薄、眉眼简单、唇色自然；日常外出用。
- 通勤淡妆：在日常淡妆基础上稍整齐利落；工作日通勤用。
- 正式妆：底妆完整、眼妆与唇色加强；正式场合、拍照用。

## 发型池
- 自然披发：日常通用。
- 低马尾：通勤、运动前后。
- 丸子头：居家、休闲。
- 短发利落款：适用于短发角色的日常造型（洗后自然吹干即可）。
