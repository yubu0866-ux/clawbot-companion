# 媒体生成与配音/TTS（可选接口）

媒体与配音都是**可选能力，默认关闭**（`config.json` 的 `media.photo_enabled` / `media.video_enabled` 均为 `false`）。本项目只约定接入点，不绑定任何具体厂商，也不包含任何声音克隆流程。

## 生成器接口约定

部署方如需图片/视频能力，实现一个生成器并在 worker 生成层调用即可。约定（语言无关的逻辑接口）：

```
generate(kind, prompt, references, options) -> { file_path, width, height, duration_sec? }
```

| 参数 | 说明 |
|---|---|
| `kind` | `image` 或 `video` |
| `prompt` | 文本提示；应结合内容包（衣橱/场景卡/表情/妆容）组装，保证角色与场景一致 |
| `references` | 参考图本地路径数组（可为空）；只使用部署方有权使用的素材，本地素材不要擅自上传到公网服务 |
| `options` | 尺寸、时长等可选参数 |

返回值 `file_path` 为本地相对路径，随后通过出站通道发送（agent 模式下填入出站文件的 `media_file` / `media_type`）。

行为约定：

- 生成失败时降级为纯文字回复，不要让整轮聊天失败。
- 主动消息是否带媒体由 proactive 决策层按 `media.*_weight` 裁定一次，生成层不要二次随机。
- 生成内容应与人设与内容包一致，并遵守所用生成服务的内容政策。

## 出站视觉质检

生成出来的图片/视频在发送前过两层质检，顺序固定：

1. **机器检**：跑 `scripts/media_screen.py <文件>`——解码完整性、规格（时长/大小/分辨率）、抽首/中/尾三帧，并自动串 `audio_screen.py` 过音轨门。`ok=false` 不发送。
2. **视觉判断**（机器检不冒充这一层）：打开成品与抽帧逐项看——
   - 人脸与部署方提供的身份参考图（角色锚图＋脸部特写）一致，无脸漂移；
   - 穿搭与当日形象/内容包口径一致；
   - 无多指、肢体扭曲、五官错位等畸变，无乱码文字；
   - 视频另看首/中/尾三帧之间脸是否漂移、动作是否连贯。

处置：不合格按原提示词重出一次；再不合格降级（视频→照片→纯文字）。同一轮同一件媒体生成尝试至多两次，不要无限重出。带台词的视频还要按下面的配音口径回听核对（转写比对台词、口型与时间点对齐）。

## 提示词包络与平台接受台账（方法论）

生成平台的内容审核边界只能靠实证摸清，靠猜测 either 过度收敛（画面信息被静默删）or 反复撞墙。建议部署方自建一份「平台接受台账」，与本节口径配套维护：

- **只记生产实证**：每条注明日期、组合摘要、结果（通过/拦截）与证据（成品或交付记录路径）；没真跑过的不记。
- **分类归因**：拦截按三类记——措辞触发 / 装扮本体 / 机位构图；另设「未过但非审核」一类（生成失败、参考图不稳定等），单列存放，**不入拦截台账、不当包络边界**，避免把偶发失败误判成审核红线。
- **措辞口径**：描述性事实写满——款式、材质、颜色、贴合、覆盖、姿态、场景、镜头照实写；只避台账实证过的触发项与不带画面信息的评价标签。不要用「一律不写某类描述」的一刀切自我收敛。
- **被拦降级阶梯**：换机位 → 换表述 → 微调构图，每步只降一格、保主体，不许直接降成清淡版；台账里有同类可过版本时直接照用。
- **保真条款**：换说法不减信息量；实证必拦的信息做降格处理并续记台账，不静默删。

台账格式示例（**格式占位，非实证记录**，部署者以自家实证续记）：

| 日期 | 类别（措辞/装扮/机位） | 组合摘要 | 结果 | 证据 | 备注 |
|---|---|---|---|---|---|
| `<YYYY-MM-DD>` | `<占位>` | `<占位：某装扮的描述性写法＋机位>` | 通过/拦截 | `<成品路径>` | `<占位>` |

## TTS / 配音接入点（可选）

如需语音消息或为视频配音，在媒体流水线的「拿到最终文本之后、合成/发送之前」接入任意 TTS 服务：

```
synthesize(text, voice_options) -> { audio_path, duration_sec }
```

- `voice_options` 只放通用参数（如语言、语速、音量），音色选择由部署方在服务商侧自行配置。
- 文本应先按气口切分短句再逐段合成，段间留自然停顿；合成后统一响度再与视频/消息合并。
- 本文档不提供、不建议任何针对真人声音的克隆流程；使用他人声音须有明确授权。
- TTS 不可用时降级为文字消息即可。
