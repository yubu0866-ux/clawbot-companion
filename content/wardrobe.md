# 衣橱（内容包示例）

> 结构示例，只含少量中性条目，可按角色设定自行扩充。生成媒体或描写日常穿搭时从这里取组合，保持同一天内一致。

## 结构

类别即 `##` 标题，必须用代码口径的类别名：`通勤 / 日常 / 居家 / 运动 / 正式`（`worker.py` 的 `daily_look` 按类别取套：工作日用「通勤」，周末在「日常 / 居家」间轮换，取不到当天类别时回落「日常」；类别名不在口径内会导致选不到套、穿搭为空）。每个类别下每套穿搭一个 `###` 标题，字段逐行写：`季节 / 场合 / 上装 / 下装 / 鞋 / 配饰 / 备注`（其中上装、下装、鞋、配饰会被解析为套装组成，至少写满两项）。

## 通勤

### 春日通勤
- 季节：春
- 场合：工作日通勤
- 上装：浅色针织开衫 + 白色内搭
- 下装：直筒长裤
- 鞋：平底乐福鞋
- 配饰：帆布托特包
- 备注：简洁清爽，适合白天外出。

## 日常

### 周末休闲
- 季节：四季（按天气增减外套）
- 场合：周末逛街 / 散步
- 上装：宽松卫衣
- 下装：牛仔裤
- 鞋：运动鞋
- 配饰：棒球帽
- 备注：舒适优先。

## 居家

### 居家日常
- 季节：四季
- 场合：在家
- 上装：纯色棉质 T 恤
- 下装：家居长裤
- 鞋：室内拖鞋
- 配饰：无
- 备注：放松状态的日常描写用。
